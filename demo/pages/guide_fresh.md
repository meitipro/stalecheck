# Quickstart: install and run

Install the tool with your package manager, then run `mytool init` in an empty
folder. The first run downloads the model files, which takes about a minute.
After that, `mytool serve` starts the local server on port 8080 and
`mytool check` prints a short health report.

If something goes wrong, run `mytool doctor`; it prints the versions it found
and the first thing to fix.
